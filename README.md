# Learning Playwright

This repository contains code and resources for learning Playwright automation.

## Project Structure

- **chapter_01_Basics**: Contains basic Playwright concepts and examples.
- **chapter_02_Java_Concepts**: Contains Java-related concepts (if applicable/planned).

## Prerequisites

- Node.js
- Playwright

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run tests:
   ```bash
   npx playwright test
   ```
